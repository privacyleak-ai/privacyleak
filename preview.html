System architecture

flowchart TB

  end

Website sampling

flowchart TD
  A[Open a public listing page] --> B{Image entries on the page?}
  B -->|No| Z[This listing section ends]
  B -->|Yes| C[Read the image id and source page]
  C --> D{Already ingested?}
  D -->|Yes| E[Skip]
  D -->|No| F[Save the image and its source]
  F --> G[Write the sample record]
  E --> H[Continue to the next item]
  G --> H
  H --> I{More items on this page?}
  I -->|Yes| C
  I -->|No| J[Go to the next public listing page]
  J --> A

Telegram sampling

flowchart TD
  A[Read the chat list] --> B[Connect to a public chat]
  B --> C{More new image messages?}
  C -->|No| H[Stop this chat here for now]
  C -->|Yes| D[Save the image file]
  D --> E[Record the message in local SQLite]
  E --> C
  E --> F[Sync new records to MySQL by time]
  F --> G[Sample record appears in the shared media table]
  D --> I[Ingest watch sees a new image]
  I --> J[Hand it to the face service]

Ingest

flowchart TD
  A[New sample image] --> B[Wait until the file is fully written]
  B --> C[InsightFace detects faces]
  C --> D{Face detected?}
  D -->|No| E[Do not write to the vector index]
  D -->|Yes| F[Generate the feature vector]
  F --> G[Write to MySQL]
  G --> H{Write confirmed?}
  H -->|No| I[Keep the image and retry next round]
  H -->|Yes| J[Sync to FAISS]
  J --> K[Delete the original for Telegram samples]
  E --> L[Keep the source record for website samples]

A query

sequenceDiagram
  actor User as User
  participant Entry as User site or Bot
  participant Face as Face service
  participant Index as FAISS
  participant DB as MySQL
  User->>Entry: Upload a face photo
  Entry->>Face: Submit the query image
  Face->>Face: buffalo_l detects the face and builds a vector
  Face->>Index: Fetch nearest neighbors
  Index-->>Face: IDs of nearby vectors
  Face->>DB: Load source pages by ID
  DB-->>Face: Page URL and title
  Face-->>Entry: Similar samples and where they came from
  Entry-->>User: Show the results
